# ABC Communications Customer Churn Analysis

## Project Overview
Customer churn analysis for ABC Communications Ltd, completed as a business analytics project with AnalystLab Africa Consulting.

## Objective
Identify customer segments and service factors associated with churn and recommend retention strategies.

## Dataset
- Records: 7,043
- Source: Telco Customer Churn Dataset
- Target: `Churn`
- Source columns: 21

## Tools
- Excel
- Python (Pandas, Matplotlib)
- PowerPoint

## Key Findings
- Overall churn rate: 26.5%
- Month-to-month churn: 42.7%
- Electronic check churn: 45.3%
- Fiber optic churn: 41.9%
- 0–12 month churn: 47.4%
- No Tech Support churn: 41.6%

## Recommendations
1. Strengthen first-year retention.
2. Incentivize longer contracts.
3. Promote automatic payment.
4. Investigate fiber-optic churn drivers.
5. Bundle Tech Support and Online Security.
6. Monitor high-risk segments monthly.
